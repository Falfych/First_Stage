# Эмулятор командной строки UNIX-подобной ОС

## Описание проекта
Данный проект представляет собой консольное приложение (CLI), имитирующее работу интерфейса командной строки UNIX-подобных операционных систем. Проект разрабатывается в рамках дисциплины **«Конфигурационное управление»** (Вариант №8).

---

## Что реализовано (Этап 1: REPL)
В рамках первого этапа был успешно создан минимальный прототип интерактивной оболочки (интерфейс REPL):
* **Консольный интерфейс (CLI):** Реализовано интерактивное диалоговое окно для ввода команд.
* **Кастомизация приглашения:** Строка ввода содержит уникальное имя виртуальной файловой системы (`MyVFS`).
* **Парсер переменных окружения:** Реализован автоматический разбор и раскрытие системных переменных окружения (например, `$USERNAME`, `$USERPROFILE`) на уровне реальной ОС.
* **Команды-заглушки:** Добавлены обработчики для базовых команд навигации `ls` и `cd`, выводящие имя команды и переданные аргументы.
* **Команда выхода:** Реализовано корректное завершение работы сессии по команде `exit`.
* **Устойчивость к ошибкам:** Добавлена базовая обработка неизвестных команд, исключающая аварийное завершение программы при некорректном вводе.

## Как запускать проект

### Требования
* Установленный интерпретатор **Python 3.x**
* Среда разработки (рекомендуется **Microsoft Visual Studio** или **VS Code**)

### Инструкция по запуску
1. Склонируйте репозиторий или откройте корневую папку проекта в Visual Studio.
2. Перейдите в каталог `src/` и запустите главный файл скрипта:
   ```bash
   python src/_1__Практическая.py
   ```
3. Для завершения работы введите в терминале команду `exit`.

## Этап 2: Конфигурация и логирование

Реализована настройка параметров командной строки и логирование действий эмулятора оболочки ОС.

### Новые возможности:
* **Парсинг аргументов:** Поддержка ключей `--vfs`, `--log` и `--script` с помощью библиотеки `argparse`.
* **Логирование:** Автоматическая запись всех выполненных команд в XML-файл с фиксацией даты, времени и аргументов.
* **Стартовый скрипт:** Пакетный режим выполнения команд из файла перед переходом в интерактивный режим (с остановкой при первой ошибке).
* **Скрипт автоматизации:** Создан файл `run.bat` для быстрого запуска тестов в ОС Windows.

### Пример запуска:
```bash
python src/first.py --vfs ./vfs.zip --log ./log.xml --script ./start.txt
```
## Этап 3: Виртуальная файловая система (VFS)

Реализована полноценная интеграция виртуальной файловой системы на основе XML-файла. Все операции по навигации и чтению выполняются строго в оперативной памяти без распаковки на физический диск.

### Новые возможности:
* **Поддержка XML VFS:** Чтение древовидной структуры директорий и файлов из конфигурационного XML-файла.
* **Команда `ls`:** Вывод списка вложенных папок и файлов для текущей активной директории VFS.
* **Команда `cd`:** Навигация по виртуальным директориям с корректной обработкой путей, переходов на уровень вверх (`..`) и возврата в корень (`/`).
* **Команда `cat`:** Чтение содержимого виртуальных файлов с автоматическим декодированием бинарных данных из формата Base64.
* **Проверка целостности (Валидация):** Реализована обработка ошибок загрузки VFS (проверка существования файла и валидности корневых тегов XML).

### Структура тестовых сценариев:
Для комплексного тестирования (включая проверку не менее 3 уровней вложенности) подготовлены раздельные конфигурации:
1. `run.bat` + `vfs_minimal.xml` — проверка инициализации пустой VFS.
2. `run_normal.bat` + `vfs_normal.xml` + `start_normal.txt` — базовые команды чтения файлов.
3. `run_high.bat` + `vfs_high.xml` + `start_deep.txt` — глубокий тест навигации по 3 уровням папок и декодирования.
